# 100xDevs Offline Course Toolkit

> A production-grade offline learning platform built in Python — featuring a parallel video downloader, GPU-accelerated auto-subtitle generator, and a premium browser-based media player dashboard.

[![Python](https://img.shields.io/badge/Python-3.11+-blue?logo=python)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-green)](LICENSE)

## Overview

This toolkit was built to download, organize, and play back an entire 100xDevs cohort course library offline. It solves three real-world engineering problems:

1. **Reliable bulk video downloading** with resilience against network failures and deduplication of shared videos across courses.
2. **Automatic AI-powered subtitle generation** using OpenAI Whisper running on a local GPU — no API keys, no cost, fully private.
3. **A polished offline video player** with smart navigation, progress memory, and subtitle rendering, served from a local HTTP server.

## Features

### `download_course.py` — Parallel Video Downloader & Scraper

- **Concurrent Downloads** — Thread-safe parallel download manager using `ThreadPoolExecutor`, running up to 3 streams simultaneously with per-thread progress logging.
- **Exponential Backoff Retry** — Automatically retries failed downloads up to 5 times with increasing wait intervals to survive DNS hiccups and rate-limiting.
- **Range-based Resume** — Partial downloads resume from the last byte offset via HTTP `Range` headers, avoiding redundant re-downloads.
- **Stream Integrity Validation** — Runs `ffprobe` on every downloaded file to verify H.264 stream integrity and container health before marking it complete.
- **NTFS Hardlink Deduplication** — Detects videos that are shared across multiple courses (e.g., a DSA lecture appearing in both Web Dev and DevOps cohorts) and creates NTFS hardlinks instead of duplicating the file — providing **20+ GB in storage savings** with zero data redundancy.
- **Secure Token Loading** — Authorization JWT is loaded from the `COHORT_TOKEN` environment variable or a local `.env` file, never hardcoded.

### `generate_subtitles.py` — GPU-Accelerated Subtitle Generator

- **Local AI Transcription** — Uses `faster-whisper` (OpenAI Whisper `small` model via CTranslate2) to transcribe audio directly on the local machine.
- **CUDA GPU Acceleration** — Automatically detects and uses NVIDIA GPU via CUDA `float16` for ~10x real-time transcription speed. Falls back gracefully to CPU `int8` on machines without a supported GPU.
- **Windows DLL Auto-Discovery** — Dynamically registers pip-installed NVIDIA CUDA library paths (`cublas`, `cudnn`, `cuda_runtime`) into the Windows DLL search path and `PATH` at startup, eliminating the need for a system-level CUDA Toolkit installation.
- **WebVTT Output** — Generates correctly formatted `.vtt` subtitle files co-located with their source video files for native browser `<track>` element compatibility.
- **Language Detection** — Auto-detects spoken language per file using Whisper's built-in detection (prints confidence score).

### `index.html` + `start_player.py` — Offline Media Player Dashboard

- **Local HTTP Server** — `start_player.py` spawns a `http.server` instance and launches the dashboard in the default browser, bypassing browser CORS restrictions that block local `file://` video playback.
- **Collapsible Sidebar Navigation** — Dynamically rendered course tree (courses → weeks → lectures) built from the `course_data.js` database generated by the organizer script.
- **Real-time Search** — Instant full-text title filtering across all 295 lectures using a live `<input>` event listener.
- **Subtitle Track Auto-loading** — On every video load, the player checks for a co-located `.vtt` file and dynamically injects a native `<track kind="subtitles">` element, enabling browser-native closed captions with zero configuration.
- **Playback Controls** — Speed selector (0.5x–3.0x), keyboard shortcuts (`Space` for play/pause, `←`/`→` for 10-second seek), and autoplay-next logic.
- **Watch Progress Persistence** — Uses `localStorage` to persist and restore the last-played timestamp and video across sessions, and shows a ✓ indicator on completed lectures.

### `organize_weeks.py` — Organizer & Integrity Reporter

- **Chronological Sorting** — Parses lecture titles using regex (e.g., `1.1`, `Week 24.2`) and re-organizes them into zero-padded week directories (`Week 01` … `Week 24`) for alphabetical filesystem ordering.
- **Integrity & Storage Reports** — Prints a full download validation report: total videos, validated count, pending items, failed attempts, physical disk usage, and deduplication savings in GB.

## Getting Started

### Prerequisites

Ensure `ffmpeg` and `ffprobe` are installed and available on your system PATH:

```bash
ffmpeg -version
ffprobe -version
```

### 1. Clone & Configure

```bash
git clone https://github.com/<your-username>/100xdevs-toolkit.git
cd 100xdevs-toolkit

# Copy the env template and fill in your token
cp .env.example .env
# Edit .env and set COHORT_TOKEN=Bearer <your_jwt_token>
```

> **How to get your token:** Open DevTools on `app.100xdevs.com` → Network tab → click any API request → copy the `Authorization` header value.

### 2. Install Dependencies

```bash
pip install -r requirements.txt

# For GPU-accelerated subtitles (Windows + NVIDIA GPU):
pip install nvidia-cublas-cu12 nvidia-cudnn-cu12 nvidia-cuda-runtime-cu12
```

### 3. Download the Course

```bash
python download_course.py
```

Downloads are saved to `downloads/Complete Devops Cohort/` and `downloads/Complete Web Development Cohort/`.

### 4. Organize by Week

```bash
python organize_weeks.py
```

Groups videos into `Week 01`, `Week 02`, … directories and prints the integrity & storage report.

### 5. Generate Subtitles (Optional, GPU recommended)

```bash
python generate_subtitles.py "downloads/Complete Devops Cohort/DevOps Cohort Videos/Getting started with devops"
```

Generates `.vtt` subtitle files next to each `.mp4` file. The player loads them automatically.

### 6. Launch the Offline Player

```bash
python start_player.py
```

Opens the dashboard at `http://localhost:8000/index.html`.

## Key Engineering Decisions

| Problem | Solution |
|---|---|
| 295 videos × slow sequential downloads | `ThreadPoolExecutor` with 3 concurrent workers |
| Re-downloading on interruption | HTTP `Range` header resume from last byte |
| Same video in 2 courses = double storage | NTFS `os.link()` hardlinks — zero extra bytes |
| No CUDA Toolkit installed on machine | pip-installable NVIDIA wheels + dynamic `os.add_dll_directory()` |
| CORS blocking local `file://` video | Local `http.server` via `start_player.py` |
| Subtitles not loading in player | Dynamic `<track>` injection on every video load event |
